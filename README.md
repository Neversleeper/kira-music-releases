# Kira Music

A music player for Windows.

## Download

Click **Kira-Music-Setup-<version>.exe** in the file list above, then press the download button, and run it.

Windows may show a blue "Windows protected your PC" window because the installer is not signed yet: press **More info**, then **Run anyway**.

Kira Music updates itself after it is installed.

## Share page

`s/` is the small page that a shared song or playlist link opens (it offers "Open in Kira Music").
